# **06. 미니골프 — 은행 탈출 기획**

> 다이아를 훔친 골프공이 경비를 피해 은행을 탈출한다.

- 근거 문서: `06. Mini Golf 과제 작업지시서.md`
- 과제 조건: 새 장애물 **최소 3종**, 소개 · 응용 · 심화 **3홀**, 총 플레이 타임 3분 이상, 마감 **10/8**

---

## **1. 장애물 3종 한눈에 보기**

장애물 하나는 플레이어에게 던지는 **질문 하나**다. 세 장애물이 서로 다른 질문을 하도록 나눈다.

| 장애물 | 플레이어에게 묻는 것 | 핵심 규칙 | 주로 쓰는 손잡이 |
| :--- | :--- | :--- | :--- |
| **CCTV** | "어디에 멈출래?" | 고정된 채 좌우(또는 앞뒤)로 스캔. 시야 안에 **N초 이상** 머물면 걸림. 빨리 지나가면 안전 | 파워 정밀도 |
| **경비원** | "어디로 비켜 갈래?" | 정해진 구간을 왕복 순찰. **몸에 닿으면** 걸림. 레인의 일부만 막아서 옆으로 돌아갈 수 있음 | 조준 정밀도, 경로 선택 |
| **레이저** | "언제 지나갈래?" | 제자리에 고정, **레인 폭 전체**를 막고 일정한 박자로 켜졌다 꺼짐. 켜져 있을 때 닿으면 걸림 | 타이밍 창 |

### **걸렸을 때 (공통)**

- "게임 오버" = **직전 샷 위치로 복귀** (작업지시서의 낙하 규칙과 같은 방식)
- 실패의 대가는 코스별로 조절할 수 있다 (소개: 작게 → 심화: 크게)

---

## **2. 장애물 상세**

### **CCTV**

- 고정된 위치에서 일정 각도를 좌우(또는 앞뒤)로 일정 시간 동안 스캔한다.
- 공이 시야 안에 들어오면 시간을 잰다. **N초 이상** 머물면 걸린다.
- 시야를 빠르게 **지나가는 것은 괜찮다** → 시야 안에서 **멈추지 않게** 파워를 맞추는 것이 핵심.
- (선택) 기둥 · 금고 뒤에 공이 가려지면 안 보이게 해서 "그늘에 멈추기" 플레이를 만든다.

### **경비원**

- 지정된 두 지점 사이를 왕복하며 순찰한다.
- 경비원 몸에 닿으면 걸린다.
- **레이저와의 차이: 레이저는 길 전체를, 경비원은 길의 일부만 막는다.**
  - 경비원이 오른쪽에 있으면 왼쪽으로 지나가면 된다 → "**어디로** 칠까"
  - 경비원 크기는 레인보다 충분히 작게 (예: 레인 3 m · 경비원 1 m), 순찰 범위도 레인 일부로만 잡는다.

```
위에서 본 모습 (폭 3 m 레인)

│    👮 →→→       │  ← 1 m 몸통이 좌우로 왕복
│                 │
│        ●        │  ← 경비원 반대쪽으로 조준해서 통과
```

### **레이저**

- 제자리에 고정된 채 레인 끝에서 끝까지 막는다.
- **점멸식**: 일정한 박자로 켜졌다 꺼진다. **꺼지기 전 · 켜지기 전 예고(깜빡임)는 넣지 않는다.**
- 박자가 항상 같으므로 플레이어는 치기 전에 몇 번 지켜보고 **감으로** 타이밍을 잡는다.
- 피할 방법이 없고 기다렸다가 꺼진 순간에 지나가야 한다 → "**언제** 칠까"

```
위에서 본 모습 (폭 3 m 레인)

│ ═══════════════ │  ← 켜짐 / 꺼짐 반복 (고정 박자)
│                 │
│        ●        │
```

## **3. 코스 배치 시 참고**

- 소개 홀에서는 레이저를 출발점 가까이 두고, 꺼져 있는 시간을 넉넉히 준다. (공이 레이저까지 굴러가는 시간도 파워에 따라 달라지므로 감 잡기 쉽게)
- 응용 · 심화 홀에서 쓸 수 있는 조합 예:
  - 레이저 점멸을 빠르게 / 레이저 2~3줄의 박자를 엇갈리게
  - 레이저 바로 뒤에 경비원 배치 (언제 + 어디로)
  - CCTV 시야 안에 쉬는 평지를 두지 않기 → 한 번에 시야를 지나가도록 파워 요구
- 지시서 규칙: 소개 홀에서 보여 주지 않은 장애물을 응용 · 심화 홀에서 처음 등장시키지 않는다.

## **4. 구현 메모**

| 장애물 | 구현 방향 |
| :--- | :--- |
| 공통 | 걸리면 `GolfBall.ReturnToLasShotPosition()` 호출 (이미 public으로 있음) |
| 경비원 | Kinematic Rigidbody + `MovePosition` 으로 두 지점 왕복, Trigger로 공 감지 |
| 레이저 | 코루틴/타이머로 일정 간격마다 Collider + Renderer On/Off, Trigger로 공 감지 |
| CCTV | `Vector3.Angle`(또는 내적)으로 시야각 안인지 판정 + Raycast로 가림 여부 확인, 시야 안에 머문 시간 누적 → N초 넘으면 복귀 |
